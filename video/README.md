# Demo video

The Neighborhood Hacks demo video, built with [Remotion](https://www.remotion.dev): the screen recording, the camera takes, deck slides, captions, and callouts, all as React components driven by time.

```bash
npm install
npm run studio     # preview in the browser
npm run render     # picture only, to out/demo-video-picture.mp4 (about 15 to 30 minutes)
npm run mux        # adds the audio from ../takes/rough-cut-v2.mp4, to out/demo-video.mp4
```

## Where things live

- `src/timeline.ts`: every time and place in the video (cuts, camera moves, slides, callouts). Change timing here.
- `src/components/`: one layer each. `Screen` (recording, zooms, Gmail tab blur), `Callouts`, `Slides`, `PrivacyList`, `Captions`, `Camera`, `NameTitle`.
- `src/lib/motion.ts`: the one spring used for all motion (settles without overshoot).
- `src/data/captions.json`: generated by `scripts/captions.ts` from whisper.cpp transcripts.

## Media (not in git)

`public/media/` holds the screen recording (an APFS clone, `cp -c`; Remotion's file server does not follow symlinks) and the camera takes converted to a steady 30 fps with a keyframe every second. Chrome records takes at a variable frame rate with keyframes about 3 seconds apart, which made frame lookups time out mid-render. Convert any new take the same way:

```bash
ffmpeg -i ../takes/<take>.mp4 -an -vf fps=30 -c:v libx264 -preset veryfast -crf 16 -g 30 -pix_fmt yuv420p public/media/<take>.mp4
```

`public/slides/` holds the pitch deck pages as 1920x1080 PNGs.

## Audio

The render is picture only. The audio comes from `../takes/rough-cut-v2.mp4`, which was checked for sync against every take. `timeline.ts` places everything on that same timeline, so the two line up frame for frame.
